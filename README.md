# Plop

떠오른 할 일을 날짜 없이 적어 두면, AI가 내 습관을 보고 캘린더 빈 시간에 배치를 제안하는 플래너입니다.
기획은 [PLAN.md](./PLAN.md)에 있습니다.

## 준비

- Node 22.12 이상, pnpm
- [Claude Code](https://code.claude.com)를 설치하고 터미널에서 `claude`로 한 번 로그인해 둡니다. Plop은 내 구독으로 로그인된 Claude Code를 실행해서 AI 기능을 씁니다.

## 실행

```bash
pnpm install
pnpm start   # 매일 쓰는 버전. 브라우저에서 http://127.0.0.1:4317
pnpm dev     # 개발용. http://localhost:5173 (데이터는 ./.data에 따로 저장)
pnpm db:seed # 개발용 데이터에 예시 할 일 넣기
```

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 일정 만들기 | 캘린더 빈 칸을 끌고 이름 입력 |
| 옮기기, 길이 바꾸기 | 일정을 끌기, 아래 끝을 끌기 |
| 완료 | 일정 왼쪽 네모 누르기 |
| 날짜 없이 적어 두기 | 오른쪽 목록 맨 위 입력칸 (AI가 알아서 묶음) |
| 목록에서 캘린더로 | 목록의 할 일을 캘린더 칸에 끌어 놓기 |
| 캘린더에서 목록으로 | 일정을 오른쪽 목록 위에 끌어 놓기, 또는 일정을 눌러 '목록으로 보내기' |
| 글로 시키기 | 아래 채팅창. 예: "내일 오후 2시 치과", "오후 다시 짜 줘", "난 오전에 집중이 잘 돼" |
| AI 배치 제안 | '계획 짜기' 버튼. 흐린 점선 칸을 눌러 확정하거나 지우기 |
| AI가 참고하는 내 습관 보기 | 오른쪽 위 사람 아이콘, "Plop이 아는 나" |
| TickTick에서 옮겨 오기 | 오른쪽 위 더 보기 > TickTick 가져오기 (설정 > 계정 > 백업의 CSV) |

AI는 이럴 때 먼저 움직입니다.

- 하루 처음 열 때, 오른쪽 목록에 할 일이 있으면 오늘 빈 시간에 배치를 제안합니다.
- 끝날 시간이 지났는데 완료 체크가 없으면 남은 빈 시간으로 옮기자고 한 번 묻습니다.

## 단축키

| 키 | 동작 |
|---|---|
| N | 목록에 새 할 일 적기 |
| / 또는 ⌘K | 채팅창으로 가기 |
| P | 계획 짜기 |
| T | 오늘로 이동 |
| ← → | 이전, 다음 기간 |
| 1 2 3 | 하루, 5일, 주 보기 |
| I | 할 일 목록 열고 닫기 |
| ? | 단축키 보기 |

## 데이터 위치

- `pnpm start`: `~/Library/Application Support/Plop/plop.db`
- `pnpm dev`: 저장소 안 `./.data/plop.db` (git에 올라가지 않음)

다른 위치를 쓰려면 `PLOP_DATA_DIR`을 지정합니다. 백업은 이 파일을 복사하면 됩니다.

## 테스트

```bash
pnpm typecheck
pnpm test    # 서버, 반복 규칙, 빈 시간 계산, TickTick 가져오기
pnpm e2e     # 실제 브라우저에서 주요 조작. AI는 가짜(PLOP_AI_FAKE=1)를 씁니다.
```

## 설정

| 환경 변수 | 기본값 | 뜻 |
|---|---|---|
| `PLOP_AI_FAST_MODEL` | `haiku` | 채팅, 자동 묶음에 쓰는 모델 |
| `PLOP_AI_SMART_MODEL` | `sonnet` | 배치 제안에 쓰는 모델 |
| `PLOP_CLAUDE_BIN` | `claude` | Claude Code 실행 파일 |
| `PLOP_PORT` | `4317` | 로컬 서버 포트 |
